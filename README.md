# MSTY 기록장

MSTY 주간 분배금을 전부 재매수할 때, 보유 주수·평균 단가·총수익률을 기록하고
52주 뒤를 낙관/보통/비관 시나리오로 시뮬레이션하는 웹 앱입니다.
서버·로그인 없이 브라우저(localStorage)에만 저장됩니다. 현재 주가·환율은 무료 API에서 자동으로 가져올 수 있습니다(직접 입력도 가능).

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭(file://)하면 동작하지 않을 수 있어요. 간단한 로컬 서버로 여세요.

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 테스트

```bash
npm test          # 또는 node tests/run.js  (Node.js 18 이상)
```

Node가 없으면 로컬 서버를 켠 뒤 `http://localhost:8000/tests/` 를 열어도 같은 테스트가 실행됩니다.

## GitHub Pages 배포

저장소 Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/ (root)`.
빌드 과정이 없어서 파일 그대로 올라갑니다.

## 앱으로 설치 (PWA)

- 크롬·엣지 주소창 오른쪽의 설치 아이콘(또는 메뉴 → 앱 설치)으로 설치하면 주소창 없는 독립 창으로 열립니다.
- 인터넷이 없어도 앱 화면과 저장된 기록이 열립니다. 시세는 마지막으로 가져온 값을 "예전 값" 표시와 함께 보여 줍니다.
- 업데이트는 **파일 묶음 단위로 한꺼번에** 바뀝니다. `sw.js`의 `BUILD`는 앱 파일 전체로 만든 지문이고,
  새 서비스 워커는 모든 파일을 받아 지문이 맞을 때만 설치됩니다. 배포 도중처럼 서버에 옛 파일과 새 파일이
  섞여 있으면 설치를 미루고 예전 묶음을 그대로 씁니다. 새 버전이 설치되면 앱이 한 번 새로고침됩니다.
- **앱 파일을 고친 뒤에는 커밋 전에 꼭 `npm run stamp`** 를 실행하세요(`sw.js`의 `BUILD` 갱신).
  잊으면 `npm test`가 실패해서 알려 줍니다.
- 새 파일을 추가하면 `sw.js`의 `SHELL_FILES` 목록에도 넣고 `npm run stamp` 하세요. 빠지면 `npm test`가 알려 줍니다.

## 시세 자동 가져오기

| 항목 | 제공처 | 키 | 무료 한도 | 데이터 시점 |
|---|---|---|---|---|
| 주가 (기본) | [Finnhub](https://finnhub.io) | 필요 (무료) | 분당 60회 | 미국 주식 실시간 (`/quote`) |
| 주가 (대안) | [Twelve Data](https://twelvedata.com) | 필요 (무료) | 분당 8회, 하루 800회 | 미국 주식 실시간 |
| 환율 (기본) | [Frankfurter](https://frankfurter.dev) | 불필요 | 할당량 없음(남용 방지 제한만) | 중앙은행 고시 환율, **하루 1번** |
| 환율 (예비) | [ExchangeRate-API](https://www.exchangerate-api.com) | 불필요 | 초과 시 20분 차단 | **하루 1번** |
| 참고: MSTR | 주가와 같은 제공처 (Finnhub / Twelve Data) | 필요 | 위와 같음 | 실시간, 전일 대비 등락률 |
| 참고: 비트코인 | [CoinGecko](https://www.coingecko.com) | 불필요 | IP별 제한(숫자 비공개) | 수십 초~1분 간격, 24시간 등락률 |
| 참고: 비트코인 (예비) | [Coinbase Exchange](https://www.coinbase.com) | 불필요 | IP별 초당 10회 | 실시간, 24시간 시가 대비 |

- API 키는 설정 화면에서 입력하며, 이 브라우저의 localStorage(`msty-tracker-api`)에만 저장됩니다. 코드·저장소·백업 JSON 파일에는 들어가지 않습니다.
- 가져온 값은 10분 동안 재사용합니다. "새로고침" 버튼은 바로 다시 가져옵니다.
- 가져오기에 실패하면 칸에 있던 값(마지막으로 가져온 값이나 직접 입력한 값)을 그대로 씁니다.
- MSTR·비트코인은 성적표의 "참고 시세" 카드에만 보이고 수익률 계산에는 쓰지 않습니다. Finnhub 무료 `/quote`는 미국 주식 전용이라 비트코인은 키 없는 공개 API로 가져옵니다.

## 매도 기록

"분배 기록" 탭 아래쪽에서 날짜, 판 주수, 매도 가격($), 수수료($), 원화로 바꿨다면 그때 환율을 적습니다. 잘못 적은 기록은 수정·삭제할 수 있습니다.

- 팔면 보유 주수가 줄고, 원금은 `판 주수 × 평균 원금(남은 원금 ÷ 보유 주수)`만큼 빠집니다. 남은 주식의 평균 단가는 그대로입니다.
- 실현 손익(달러) = 수수료 뺀 판 돈 − 판 주수 × 평균 단가 (증권사와 같은 방식)
- 실현 손익(원화) = 수수료 뺀 판 돈 × 환율 − 판 주식의 원금 몫 (원화로 안 바꿨으면 현재 환율)
- 성적표의 **남은 주식 기준** = (평가금액 − 남은 원금) ÷ 남은 원금, **전체 기준** = (평가금액 + 판 돈 − 처음 원금) ÷ 처음 원금
- 판 돈은 재매수용 현금에 섞지 않습니다. 시뮬레이션은 남은 주식에서 시작합니다.
- 매도 기록이 없으면 모든 숫자가 매도 기능을 넣기 전과 똑같습니다. `tests/fixtures/no-sell-golden.json`(매도 기능 전 코드로 계산해 둔 43가지 경우)과 비교해 확인합니다. 이 파일은 다시 만들지 마세요.
- 백업 파일에 매도 기록도 들어갑니다. 예전 백업은 매도 기록 없이 그대로 불러옵니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (성적표 / 분배 기록 / 시뮬레이션 / 설정 탭) |
| `css/style.css` | 모양. 폰 우선, 다크 모드 지원 |
| `js/calc.js` | **계산 로직만** (보유 주수, 평균 단가, 수익률, 시뮬레이션). 화면과 분리되어 테스트 가능 |
| `sw.js` / `manifest.webmanifest` / `icons/` | 앱 설치(PWA): 오프라인 화면, 새 버전 반영, 앱 이름·아이콘 |
| `js/quotes.js` | 주가·환율 API 호출, 10분 재사용, 실패 처리, API 키 저장 |
| `js/storage.js` | localStorage 저장, JSON 백업 내보내기·불러오기 |
| `js/chart.js` | 외부 라이브러리 없이 SVG 꺾은선 그래프 그리기 |
| `js/app.js` | 입력을 읽고 계산 결과를 화면에 표시 |
| `scripts/` | `npm run stamp`: 서비스 워커 지문(BUILD) 갱신 |
| `tests/` | 계산 로직 테스트 (터미널·브라우저 둘 다 실행 가능) |
